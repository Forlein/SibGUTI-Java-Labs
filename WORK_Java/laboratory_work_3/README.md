# Лабораторная работа 3. Полиморфизм и проектирование на Java

15 заданий, каждое — отдельная папка с номером. Внутри каждой папки лежат
исходники `*.java` (главный класс с методом `main`).

Темы работы: динамическая диспетчеризация, перегрузка и переопределение
методов, интерфейсы и абстрактные классы, композиция и делегирование,
контракты `equals`/`hashCode`, `sealed`-иерархии и расширяемый движок правил.

Каждое задание компилируется и запускается независимо. Классы с одинаковыми
именами (`Course`, `Main`, `NotificationSender` и т. п.) продублированы в разных
папках, поэтому собирать задания нужно по отдельности.

Сборка и запуск одного задания (достаточно JDK 21, Maven не нужен):

```
javac -encoding UTF-8 -d out <папка>\*.java
java -Dstdout.encoding=UTF-8 -cp out <ГлавныйКласс>
```

Готовый отчёт по работе — `Отчет_ЛР3_Java.docx` и `Отчет_ЛР3_Java.pdf`.

## Задания

| Папка | Задание |
|---|---|
| `1` | Один контракт, две реализации: интерфейс `CourseFormatter` и две реализации |
| `2` | Dynamic dispatch: перегрузка против переопределения в иерархии `NotificationSender` |
| `3` | Полиморфный массив и обход циклом `for-each` без `if` |
| `4` | Абстрактный базовый класс: `final`-алгоритм и точка расширения `doSend` |
| `5` | Интерфейс или абстрактный класс: `Identifiable`, `BaseEntity`, `Formatter` |
| `6` | Переопределение без случайной перегрузки: роль `@Override` |
| `7` | Композиция вместо наследования: декораторы `LoggingSender` и `RetrySender` |
| `8` | Нарушение LSP: разделение `CourseReader` и `CourseWriter` |
| `9` | Политика допуска как стратегия: интерфейс `EnrollmentPolicy` |
| `10` | Конфликт `default`-методов и его разрешение через `Interface.super` |
| `11` | Равенство в иерархии: симметрия `equals` у `Point` и `ColoredPoint` |
| `12` | `sealed`-иерархия результата и исчерпывающий `switch` без `default` |
| `13` | Удаление type code: замена `switch` по строке на полиморфизм |
| `14` | Наследование взрывает комбинации: две независимые оси через композицию |
| `15` | Расширяемый движок правил: `sealed RuleResult`, `Rule`, `AllOf`, `AnyOf` |

Требуется JDK 21.
