# Лабораторная работа 7. Файлы и потоки ввода-вывода в Java

9 заданий, каждое вынесено в отдельную папку `1`–`9`. Внутри каждой папки находится
`Main.java` с собственным методом `main`; задания собираются и запускаются независимо.

Тема работы: кодировки и буферизация, `try-with-resources`, ленивые `Stream`,
бинарные и версионируемые форматы, атомарная замена файла и потоковый импорт
больших файлов. Требуется JDK 21.

Сборка и запуск отдельного задания:

```
cd 1
javac -encoding UTF-8 -d out Main.java
java -Dstdout.encoding=UTF-8 -cp out Main
```

Готовый отчёт по работе — `Отчет_ЛР7_Java.docx` и `Отчет_ЛР7_Java.pdf`.

## Задания

| Папка | Задание |
|---|---|
| `1` | Каталог курсов в UTF-8: сохранение и чтение, отсутствие файла, каталог вместо файла |
| `2` | `BufferedReader`/`BufferedWriter`: счётчики строк и символов, граница `bytes → chars` |
| `3` | `try-with-resources`: исключение в середине pipeline и порядок закрытия ресурсов |
| `4` | `Files.lines`: ошибочный возврат `Stream` наружу и владение ресурсом |
| `5` | Бинарный формат: magic, version, count, `DataOutputStream`/`DataInputStream`, отказ версии и обрезке |
| `6` | Временный файл в том же каталоге, flush/close, `ATOMIC_MOVE` с fallback |
| `7` | Частично повреждённый импорт: ошибки с номерами строк, all-or-nothing и sealed-результат |
| `8` | Потоковый импорт большого файла: счётчики, ограниченный список ошибок, отмена по порогу |
| `9` | Версионируемый формат: schema version, CRC32, миграция v1 → v2, отказ будущей версии |
