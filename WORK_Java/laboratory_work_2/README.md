# Лабораторная работа 2. Исключения в Java

15 заданий, каждое в своей папке-модуле. Внутри каждой папки:

- `main` — файлы классов,
- `test` — файлы тестов (задания 08–15),
- `data` — входные данные (задания 12 и 15).

Каждое задание собирается независимо, общие классы копируются в папку задания
и помечены комментарием `КОПИЯ ФАЙЛА` с указанием, из какого задания они пришли.

Сборка всех заданий разом:

```
mvn test
```

Сборка одного задания:

```
mvn -pl 06_course_import test
```

## Задания

| Папка | Задание |
|---|---|
| `01_stack_trace` | Разбор трассировки стека |
| `02_checked_and_unchecked` | Проверяемые и непроверяемые исключения |
| `03_checked_exception` | Собственное проверяемое исключение |
| `04_try_catch_finally` | try / catch / finally |
| `05_try_with_resources` | try-with-resources |
| `06_course_import` | Импорт данных курса |
| `07_course_service` | Сервис курсов |
| `08_test_course_hours` | Тесты: длительность курса |
| `09_test_duration_boundary` | Тесты: граница длительности |
| `10_test_course_code` | Тесты: код курса |
| `11_test_rejection_state` | Тесты: состояние отказа |
| `12_test_stability` | Тесты: стабильность (нужна папка `data`) |
| `13_decision_table` | Таблица решений |
| `14_import_two_failures` | Две ошибки импорта |
| `15_error_boundary` | Граница ошибок (нужна папка `data`) |

Требуется JDK 8 и новее, Maven 3.6+.
